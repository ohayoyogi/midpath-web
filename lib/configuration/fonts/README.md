# Fonts

`shinonome12-unicode.bdf` is generated by `scripts/build-font.sh` from the 12-dot
[Shinonome (東雲) fonts](http://openlab.ring.gr.jp/efont/shinonome/) by Yasuyuki Furukawa
and the /efont/ project: ISO 8859-1, JIS X 0201 half-width katakana and JIS X 0208, merged
into one BDF with Unicode glyph names (`U+XXXX`) for MIDPath's BDF font renderer.

The Shinonome fonts are in the public domain (the authors declare they will not exercise
their rights), and may be freely modified, converted, embedded and redistributed.
